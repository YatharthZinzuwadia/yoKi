# Blender scripts

Headless asset scripts (run: `blender -b -P tools/blender/<script>.py`). Output goes to `public/models/`.

Planned (see docs/00-action-plan.md):
- `cast.py`: MakeHuman/MPFB2 bodies for the cast with the proportions in docs/03-cast.md
- `pile.py`: rigid-body pile of posed bodies → the corpse mountain (instancing-ready GLB + LODs)
- `props.py`: Hunter 350, beige PC/CRT, guitar, harmonium
